# 건률네 포켓몬 대시보드 🎨

건률이(2020년생)의 하루 루틴을 포켓몬 도감처럼 즐겁게 관리하는 가족용 대시보드입니다.
태블릿(가로·세로), 휴대폰, PC 브라우저 어디서든 같은 파일 하나로 열립니다.

- **앱 열기**: https://thestarking2.github.io/geonryul1-pokemon-dashboard/
- 파일: `index.html` (단일 파일, 설치 없음), `calendar.json` (가족 일정 동기화용), `manifest.json` · `sw.js` · `icon-192.png` · `icon-512.png` (홈 화면 앱)

## 태블릿 홈 화면에 앱처럼 두기 📱

1. 태블릿 브라우저(Chrome·Samsung Internet)에서 위 주소를 엽니다.
2. 주소창 옆 `⋮` → **홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
3. 바탕화면의 **건률 포켓몬** 아이콘을 누르면 주소창 없는 전체 화면 앱으로 열립니다.
   (한 번 열어 두면 인터넷이 잠깐 끊겨도 화면이 뜨고, 할 일·별 기록도 그대로 남아요.)

## 아이가 쓰는 법

1. 오늘 할 일 카드를 콕 눌러요 → 초록 체크, 효과음, XP·별이 쌓여요.
2. 3개(30 XP)를 끝내거나 한 루틴을 모두 끝내면 **몬스터볼**을 받아요.
3. `포켓몬 뽑기`로 새 포켓몬을 잡고, `도감 보기`로 설명과 기술을 읽어요.
4. 별을 모아 `보상 상점`에서 실제 보상으로 바꿔요.

## 저장과 동기화

- 할 일·XP·별·포켓몬·일정은 브라우저 **localStorage**(키 `gr_dashboard_v3`)에 저장돼요.
  기기를 바꾸려면 부모 설정 → 데이터 → **JSON 내보내기 / 불러오기**를 쓰세요.
- `calendar.json`(같은 폴더)에 아래 형식의 배열을 두면, 페이지를 열 때 자동으로 달력에 합쳐집니다.
  (직접 추가한 일정은 덮어쓰지 않아요.)

```json
[
  { "id": "a1", "date": "2026-11-24", "title": "할머니 댁 방문", "member": "family", "time": "11:00", "source": "google" }
]
```

`member` 값: `geonryul` | `mom` | `dad` | `family`

- 네이버·구글·애플 캘린더에서 내보낸 `.ics` 파일은 달력의 **📅 일정(.ics) 불러오기**로 가져올 수 있어요
  (VEVENT의 SUMMARY·DTSTART·DTEND 지원).
- 일정 정리: 날짜 상세의 담당자 칸을 눌러 한 건씩 바꾸거나, 달력 위 **🗂 일괄 관리**(부모 설정 → 데이터에서도 열려요)에서
  담당자별로 골라 **선택한 일정 담당자 변경** · **선택한 일정 일괄 삭제**를 할 수 있어요.
  `calendar.json`에서 불러온 일정은 읽기 전용으로 표시되어 여기서는 바뀌지 않아요.

## 기술 메모

- 외부: [PokeAPI](https://pokeapi.co) (포켓몬 도감), [Open-Meteo](https://open-meteo.com) (날씨), Google Fonts(Jua)
- 인터넷이 없으면 도감·날씨는 안내 문구로 대체되고, 할 일·별·일정은 그대로 동작해요.
- 개인정보(전화번호·생일·상세 주소)는 넣지 않았습니다. 날씨 좌표는 서울 상도동 기준입니다.
